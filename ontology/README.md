# ontology

The evolving semantic lexicon.

This is not Notention's type tree. Words enter from use. A class such as `job-request` is not the model.

Matching and generalized object strategy may be adapted from Notention later, where they fit. Notention's tests are not.

Revision is unsettled. A private object, not yet published, can be changed freely. A network object is hard to change, because other identities may already refer to it. How the network disposes of unwanted objects is not decided.
